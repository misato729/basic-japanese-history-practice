# 設定の変更

正本は `config/exam.json`。サービス名・案内文・色・章節・文化史区分・模試枠数・決済の有効無効を定義します。

本サービスは10枠、偶数が歴検2級日本史、奇数がセンター試験日本史です。割り当ては `exam.numbering` に定義します。章節は日本史ラボから継承した18章と各節、および未分類です。問題は未登録です。

`questions_per_exam=5` と `content/questions.json` は合成検査用の互換設定です。両試験の正式な構成・配点ではありません。実教材を作成する際に教材形式のバリデーション・画面・検査も含めて対応します。

秘密値は `.env` にのみ保持します。元サービスのDB・認証・決済設定を使わないでください。
