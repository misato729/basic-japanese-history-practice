# 模試2（歴検2級日本史型）の作成・検証記録

> 版の区分：この文書は2026-11-06の改稿前の記録です。後続の変更と検証は [改稿記録](rekiken-mock-02-revision-review.md) に分けて記録します。

確認日：2026-11-05。依頼は、リポジトリ内に配置された歴検2級の過去問を参考に模試2を作ること。追加回答の「過去問に合わせ、語句記述も含める」を採用した。先行する模試4・6・8・10の保留原稿とは別の新規依頼である。

## 成果と参照

2024年・2025年の問題・解答の原画像18頁を観察し、5大問各10問、四択45問・語句記述5問の構成を採用した。各大問に四択9問と記述1問を置いた。四択は問1〜45、記述は問46〜50とし、論述は含めない。目安50分、各問2点・計100点は本模試の学習用設定である。

主な作問根拠は山川出版社『詳説日本史』の本文で、問題・全選択肢・解説の事実を原画像で確認した。根拠欄には教科書の印刷頁と確認項目を示し、撮影PDFの位置情報と区別した。現在の小問直接根拠は67枚のローカル画像を参照する。過去問は構成・出題形式の観察に使い、共通本文と比較資料は独自の説明として作成した。

## 実施した検証

- 代表1大問で形式・本文量・最短解法・全肢説明の基準を確認してから展開した。
- 作者以外が全50問について解答を先に固定し、作者の解答と一致した。改稿時は旧版を残し、変更部分を再判定した。
- 全180肢の説明と語句記述5問について、原典の本文・脚注・図表・続き頁を必要範囲まで確認した。各大問の担当と根拠はローカルの個別記録に保存した。
- 記述5問の文字数・文字種・許容表記・不正答例を確認した。完全一致の正答露出は、全共通本文・他問・選択肢を横断して検査した。
- 問数、番号、形式内訳、配点、4択の唯一の指定、全肢説明数、根拠画像の存在とリポジトリ内配置、原稿への本文・選択肢保持、表構造、管理用情報の混入を専用検査で確認した。
- 完成セットの情報供給と4種類の原稿の対応を作者と別担当が点検した。差分形式と資料保護も検査した。

自動検査は構造・一致・存在を確かめるもので、史実の正確性を自動的に証明するものではない。原典内容と正答一意性は実際の画像照合・独立レビューで確認した。

## 修正と検証上の学び

原典との照合で表の数値1セルの誤転記を修正し、問題表と解説をそろえた。語調だけで消去しやすい誤肢を改稿し、別問題からの直接の手掛かりを除いた。頁末から次頁へ続く直接記述を追加した一方、背景のみの頁は直接根拠から分離した。原典の用字へ統一し、未確認で不要な略称例を取り除いた。

最短解法の評価では、レビュー担当の見落としを含む3件の内部評価を訂正した。整序の前後関係を1本ずつ当てはめ、残る候補数に基づいて評価した。学習者向け原稿にこの管理評価を混ぜていない。語句記述採点基準に内部の辞書形式が露出した生成箇所も修正し、通常の説明文として出力されることを再確認した。

## 限界と未実施範囲

模試1に対するユーザーの難度評価と既存の基準合わせを参照したが、多人数による平均点・正答率・所要時間の測定は行っていない。過去問と同一難度とは保証しない。基本事項だけで消去できる問題も含む。

他問の年代や背景が部分的な補助情報となる箇所はある。他問だけで全正答を確定する関係は見当たらなかったが、完全に無ヒントの50問とは評価していない。

図版・地図の識別と未知の原史料引用の読解は再現していない。美術史・音楽史を中心知識とする小問がなく、近現代の大問は10問中8問が占領期である。時代・分野が均等な測定用テストとしては扱わない。

DB登録、演習画面への追加、自動採点エンジンへの登録、コミット・push、外部公開は行っていない。新たなアプリ実装を変更していないため、アプリのビルド・UI実操作は今回の検証対象ではない。着手時から存在する別作業の変更は保持した。
