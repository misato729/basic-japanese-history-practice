# 大問の「第n問」表記の修正

確認日：2026-11-06（JST）。途中の大問で「第n問」が抜けるとの指摘を受け、原稿・DB・固定カタログ・実画面を照合した。

## 原因と修正

公開5教材30大問のうち、模試3と9は全6件、模試5は第4〜6問、模試7は第5〜6問の計17件で、保存された題名に番号がなかった。Markdown原稿では出力時に番号が補われる一方、画面の共通見出し関数は題名をそのまま使っていたため、表示が不統一になった。

`catalogGroupLabel` が構造上の `group_number` を使い、「第n問　題名」を必ず組み立てるよう修正した。既にある半角・全角数字の番号は先に取り除き、二重表示を防ぐ。題名が空の場合は「第n問」だけを表示する。演習の大問見出しとサイドバーの大問メニューに共通で反映する。「大問n」の接頭辞は追加しない。

DB・題名の原データ・問題本文・問番号・配点・回答履歴・公開状態は変更していない。

## 検証

- 公開30大問の表示値を全件検査し、番号が各1回、構造番号1〜6と一致、元の題名と固定定義に変更なしを確認。
- 別担当が関数・直接呼出2箇所・実30大問と合成入力を独立検査し、修正必須なし。半角・全角、既存番号、空題名、構造番号との一致も確認した。
- 関連する既存検査15件、型検査、差分空白検査、資料保護の追跡・全履歴検査が成功。
- PC幅1280pxとスマートフォン幅390pxで30大問ずつ計60画面を開き、全件で番号が1回だけ表示されることと、ページ全体の横はみ出し0を確認。PCのメニュー30件とスマートフォンの6件も照合し、大問移動を実操作した。
- 指摘箇所の模試7・問25が「第5問」を表示することを、PC/SPの画像と元のタブで確認。元のタブと表示幅を保持した。

詳細な全件・独立レビュー・画像は `local-only/numbered-group-headings-20261106/` に保存する。今回は表示修正のローカル確認までで、追加のコミット・push・外部公開は行っていない。
